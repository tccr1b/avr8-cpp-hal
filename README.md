This is a HAL library project which is still under developement for Atmega328p and similar
microcontrollers. The aim is building an abstraction library using C++17 while learning the language.

<li>* Gpio</li>
<li>* Timers</li>
<li>* SPI</li>
<li>* USART</li>
<li>* Interrupts</li>
<li>* Analog Comparator</li>
<li>* Adc</li>
<li>* Watchdog Timer</li>
